# Map

## 1. Usage

Adds custom map icons for configured objects, mostly for large capital ships to make their presence felt more.

## 2. Settings

| Name                        | Description                                                                                                     | Default Value |
| --------------------------- | --------------------------------------------------------------------------------------------------------------- | ------------- |
| Object Markers - Enabled    | If enabled, shows custom map icons for configured objects. Mostly used for large structures like capital ships. | True          |
| Object Markers - Show Names | If enabled, shows names for objects. | True          |
